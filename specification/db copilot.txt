====================================================================
UPDATED_AT AUTOMATION
====================================================================

All mutable tables should have:

created_at
updated_at

Use ISO8601 timestamps:

DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now'))

instead of CURRENT_TIMESTAMP.

Add automatic updated_at triggers for:

users
organizations
departments
custody_holders
certifications
holder_certifications
item_categories
item_types
serialized_items
inventory_stocks
transfer_templates
audit_sessions
audit_item_records

Trigger pattern:

CREATE TRIGGER ... AFTER UPDATE
WHEN NEW.updated_at = OLD.updated_at
BEGIN
    UPDATE ...
    SET updated_at =
        strftime('%Y-%m-%dT%H:%M:%fZ','now')
    WHERE id = OLD.id;
END;
